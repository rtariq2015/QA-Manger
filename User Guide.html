Start your local workspace

Extract the complete portable ZIP, then double-click Start CT QA Manager.cmd. The interface opens in your installed browser and runs on this computer. The required local helper and runtime are included. No public website, internet connection, runtime installer or administrator launch is required. Windows application policy must permit the included helper. Keep the complete application folder together.

Today: scanner reports and monthly evidence

While an update is running, its progress shows the current stage, processed count and elapsed time. Cancel safely stops at a safe checkpoint and keeps completed verified copies. A Windows file read may need to finish before cancellation completes. Repeat updates reuse unchanged files.

Update reports checks configured scanner folders and copies new or changed PDFs. Scanner originals are read-only. Saved reports remain available when the scanners are offline. The headline counts received Daily documents; it does not declare clinical test results passed. Monthly evidence follows your existing department checklist and explicitly reviewed items.

Reports, Review and Exports

Reports searches saved PDFs by scanner, year or multiple years, calendar month, report type, review state and search text. Open a report to enter Review, where its pages load into one large scrolling document. Scroll through the PDF without clicking Next for every page. Zoom and the collapsible queue leave more room for the report.

Exports has its own filters. Export matching reports includes every matching report, not only the highlighted row. The ZIP includes readable PDF folders, Report list.csv and an offline Report Summary.html. Extract the whole ZIP before opening its summary. Switching tabs does not discard your filters.

Pending files: Approve or Disapprove

Standard Daily reports and explicitly named Monthly documents are organized automatically. Existing approvals and disapprovals are retained. Pending contains uncertain report types, including generic files whose size or text only suggests Monthly QA. Automatic organization is shown separately from a person's saved approval.

Approve keeps the suggested document type. Disapprove rejects the suggestion and retains the PDF as Other. Either action saves immediately, clears that item from Pending and displays the next pending PDF. Undo restores the prior classification; the history remains. You can also leave a file without deciding and return later. There is no required name field, authorization checkbox, reason or second confirmation for ordinary file sorting.

These are document-organization decisions. They do not create a clinical PASS/FAIL, a verified personal reviewer or checklist evidence. The app records the action, time and Windows account identifier honestly as activity. A shared Windows login is not treated as proof of an individual reviewer. Existing clinical reviewer names and checklist selections stay unchanged.

Read report contents

Open a PDF in Review and choose Read contents. The local reader recognizes supported Siemens IEC basic and extended layouts, extracts matching report-footer dates, and shows printed observations such as OK with section references. Results are cached; unchanged PDFs do not need another full read. A failed read can be retried from the same button.

Under the selected scanner's Report formats, set Basic, Extended and Individual / combined IEC tests to Ask, Daily, Monthly or Other, then choose Save report formats. Confirm filing once per layout; recognized matching reports use that scanner rule. Ask is the initial setting because an IEC test layout alone does not establish your department's Daily/Monthly convention. Clearly titled manufacturer Daily reports are filed as Daily automatically. A saved rule applies only to that scanner. Existing approvals and Undo history are retained. Verified footer dates supply missing filing dates in the browser, readable folders and exports; historical reference dates are ignored.

Conflicting dates, unsupported formats and incomplete reads stay visible for review. Image-only PDFs still need OCR. Literal printed results are not a personal clinical approval or completed department checklist. No AI subscription, model download or internet service is used.

Readable folders

Choose Open report folders to build/open Report Library inside your configured archive. PDFs are grouped by scanner, year, month and Daily / Monthly / Other. A combined Monthly PDF and separate component PDFs can coexist. There are no extra Pending/Confirmed folder levels. The protected original archive and earlier readable copies remain intact; the app never silently deletes unrelated files.

Measurements and PDF readers

The report inspector shows supported water CT and image-noise measurements with their clearly printed HU limits, Head/Body mode, system, slice and page. The current measured number is kept separate from a parenthesized historical reference. Unsupported or ambiguous tables stay for review. These values do not create a clinical approval or completed checklist.

In Settings, PDF reader offers Automatic, Portable Python and Standard reader. All components are included and work locally. Automatic begins with Standard and can use Python if needed; this default follows the measured cold-reading comparison. The inspector identifies the reader and reading time. Selecting another reader changes future reads; it does not start a full archive reread. Choose Read contents on one older report to add its measurement details. Existing readings, file decisions and original PDFs stay preserved.

Trends: readings with source pages

Choose a scanner, water CT or image noise, period and measurement context. The graph and table show supported values printed in saved reports; select a point or source link to open its PDF page. Head/Body, system and slice contexts stay separate. Printed limits and unusual readings remain visible. Conflicting or unsupported readings stay for review. Change is the latest minus the first reading in the selected period, not a calibrated drift diagnosis or a clinical PASS.

Viewing Trends reads cached metadata only. If older reports lack measurements, choose the explicit reading action to process a bounded batch of up to 20 PDFs. Original PDFs and saved classification decisions stay intact.

Settings: connections and sign-ins

Apply your private scanner connection profile, or choose a scanner and enter its actual network folder and approved username. Enter the password in the secure field, then reconnect. A saved password is not proof of a successful connection: the actual result and Windows error number appear for that scanner. Remembered sign-ins use Windows protection bound to this account, workstation, scanner path and username. Re-enter them after a relevant change. Unrelated drive mappings and Windows sessions are preserved.

Generic downloads contain example addresses and no hospital profile or passwords. Private profiles contain paths and usernames only. If the app still says Example connection settings, apply the local profile before retrying credentials. The hospital network is needed to retrieve new scanner reports; internet access is separate.

Appearance and settings

Use the Light/Dark switch for the whole interface. The preference is saved with the workspace. Settings groups everyday connections separately from archive, reading, maintenance, updates and support tools.

Existing archives and advanced evidence tools

Use the existing program folder when upgrading. Your configured archive location and review history are retained. A newly extracted program starts with its own Data folder, so zero saved PDFs may mean you opened a different workspace. Selecting another archive never moves or deletes the previous one.

Additional Windows tools → Open original Windows interface closes the browser session and opens the original interface on the same workspace. Use it for detailed department evidence review and legacy archive tools. You can also run Start CT QA Manager.cmd classic. File-organization decisions from the browser are stored separately so they do not overwrite older formal QA review fields.

Backups, reading and support

Full backups verify archived PDFs and include the program, organizational history, configured evidence and readable report library. Save backups on approved separate storage. Saved Windows passwords are excluded. Restore opens a backup into a new folder; it does not overwrite the current archive.

Optional PDF text analysis reads new or changed files and reuses cached results. It reads one PDF at a time at lower process priority and yields between files for foreground actions. Use the compact reading bar to Pause, Resume or Stop reading. Pause takes effect after the current PDF reaches a safe checkpoint; completed readings stay saved. Review → Read & organize automatically works through pending PDFs and applies your saved scanner format rules. Settings → Reading & filing → Read all saved PDFs continues through the remaining eligible library. The separate Read next 20 saved PDFs and targeted Trends reading actions keep their bounded batches. Unknown formats stay pending; these actions do not approve clinical QA. It runs while the local app is open. Unrecognized or incomplete text stays for review; OCR is not included. No numerical acceptance limits are invented from filenames or file sizes.

Support & activity: export or print

Open Settings → Backup & support. The app keeps a local activity record of supported operations while you work. Export diagnostic ZIP collects the retained structured activity and a current diagnostic summary into one file to share when troubleshooting. It includes approved operation names, results, timings, counts, reading and filing reasons, and connection error numbers.

Open printable report prepares a readable HTML report. When it is ready, use its Open printable report link, then press Ctrl+P in that report to print or save as PDF. The diagnostic ZIP and printable-report links are independent and remain available after other work finishes.

Both outputs exclude PDFs, extracted report text, filenames, private paths, network addresses, usernames, passwords and raw logs. Nothing is uploaded automatically. Send the diagnostic ZIP for a detailed program check; use the printable report for an overview.

Offline updates and closing

Moving from version 5.2 or earlier to 5.3: extract the Upgrade ZIP into a separate folder, close the program, run Install update.cmd, and choose the existing program folder. This one-time upgrade adds the bundled Python runtime and its supported update file types. Reports, settings, saved sign-ins and approvals stay in place.

From version 5.3 onward: In Settings, choose or drop an approved Update ZIP. Check the displayed version, then install. The local host closes, the updater preserves data and settings and keeps a previous-program backup, then restarts the normal launcher. Checksums verify package consistency, not publisher identity. Use trusted packages.

Use Close local app to stop the helper when finished. Background checks and reading stop when the helper closes. A browser tab uses a local connection only; online services are disabled in this release.
