Start here

  1. Download and extract the entire ZIP into a folder on the computer's Desktop. The program does not need to be installed on a USB drive.
  2. Double-click Start CT QA Manager.cmd. Keep App and Config beside it. Normal use needs no administrator launch, Python installation or traditional installer.
  3. If hospital policy blocks it, keep the error window open and ask IT to approve or sign the application. The app preserves execution policy and endpoint protection.

First-Time Setup — once

Choose your local archive location, check the available scanners, and review the import preview. Approve the preview to copy reports. Source scanner PDFs are always read-only. If you already use v4, choose the existing archive's parent folder; its managed index and PDFs are reused. A legacy v2/v3 archive has a separate safe adoption option that verifies old hashes and preserves old files.

THE EVERYDAY ROUTINE
  1. Update reports. After setup, opening the app starts one update by default. Progress shows what is happening. You can also click Update Reports at any time. Turn off Update reports when this app opens in Advanced settings if you prefer manual updates.
  2. Open Archive review. The app identifies unavailable scanners, missing saved records, labels needing confirmation, and incomplete reviewed Monthly checklist evidence. Follow the plain-language item to the report or details.
  3. Open or export. Open Reports Folder gives you the easy folder view. Find / export reports lets you choose scanners, months, one year or several years and create a package for your computer or USB drive.

First-time copying requires preview approval. You can enable checks every 5–240 minutes while the window is open, or choose 0 minutes to pause them. Local analysis runs in batches when enabled. All checks stop when the app closes; no service or scheduled task is installed.

Prepare December, a whole year, or several years

  1. Open Find / export reports.
  2. Choose the scanner, year or Multiple… years, month and QA type. Use All months for whole years. Search by date, report name or test label if needed.
  3. Check the matching report count, then choose the export button. It includes every matching report, not only the highlighted row.
  4. Save the ZIP to a local folder or USB drive. Existing files are never overwritten; choose a new filename.

The ZIP includes the PDFs, Report list.csv, and QA Report Summary.html. The recipient can extract it, open the summary, and click through the organized PDFs without this program. The summary covers only the selected saved documents; it does not promise that every clinical QA requirement has been satisfied.

What “needs confirmation” means

Most reports are organized automatically. A possible Monthly PDF needs an authorized person to check its label and contents. A larger file, a Constancy name, or MTF wording alone is not enough to confirm an entire Monthly set. The boss does not need to check every PDF before updating or exporting.

In Check report label, open or read the PDF, choose its type, identify the reviewer, and enter a reason. If the department has configured a Monthly checklist, tick only the items actually verified in that PDF. One combined PDF or several separate PDFs can together cover the same scanner-month. The app combines reviewed items and lists what still needs confirmation in one monthly alert. No checklist is assumed by default; ask the department/QMP to provide the required items. A Monthly label alone is not proof of a complete month.

Read what is inside a PDF

Read report text extracts existing text locally and lists recognized Siemens QA terms. The bundled reader needs .NET Framework 4.7.2 or newer, normally present on current Windows workstations. It performs no separate installation, downloads no runtime, sends no PDF to a cloud service, and does not change classifications. Image-only PDFs need OCR, which is not included. Large, encrypted, unsupported or partially read files show a clear message. Limits and cancellation are cooperative between parser calls and pages; use your approved PDF viewer when complete visual inspection is needed.

Change or add a scanner

In Scanner Connections / Advanced settings, edit the scanner name, network folder, preferred letter and username. Enter a new password in the blank secure field when needed, then save. Use Add scanner for another machine. Existing scanner identities and archived PDFs are retained.

Passwords saved on Windows are DPAPI-encrypted for that Windows user and workstation. They are bound to the scanner address and username; changing either requires entering a new password. Moving the app to another Windows profile may require re-entering sign-ins. Saved passwords are never shown in fields or logs. Reconnect preserves unrelated drive mappings and existing Windows sessions.

If something needs attention

One unavailable scanner does not stop accessible scanners. An absent PDF or unconfirmed checklist item does not establish missed clinical QA. Check the department schedule, scanner records and other approved record locations. Candidate indicators begin at Edge 70 KiB and Flash/MDP 85 KiB; they never prove Monthly testing. Fast updates use metadata; the manual integrity audit checks saved PDF hashes. Source edits preserving size and timestamps are outside the fast cache's detection.

Archive, browse and export destinations must be direct local disk or USB folders. Linked folders, network destinations and mapped scanner-drive aliases are rejected. Completed verified records survive cancellation; run Update Reports again to resume. Keep metadata and PDFs together when backing up. Startup failures remain visible; details are in Logs\Startup.log in the application folder or the temporary folder.

Today and this month

The Today dashboard separates scheduled report receipt from extracted printed results. A received PDF does not automatically mean all tests passed. Configure each scanner's due day (0 means not configured), daily exceptions and approved Monthly checklist in Advanced settings. Checklist edits have an effective month so past requirements remain recorded. Historical PDFs and changed revisions remain preserved.

Analyze saved PDFs locally

Choose Analyze saved PDFs to read up to 20 uncached saved PDFs in the background. With local analysis enabled, batches continue while the app is open. Explicit printed result lines are recognized conservatively; incomplete or unrecognized text needs review. Read report text shows the extracted pages, and supporting page text is retained with findings. This does not change reviewed labels or apply unapproved numeric limits. Retry unreadable PDFs after resolving reader or permission problems.

Browse without the application

Choose Open offline library, or double-click Data/Browse Reports/Open Reports.html. Search and open ordinary PDFs without internet access. Keep the whole Browse Reports folder together when copying it. Multiple component PDFs and combined reports stay intact, with confirmed Monthly reports separate from pending verification. The page shows when it was refreshed.

Backup, restore and move

Create full backup verifies program, configuration, PDFs, metadata and analysis before publishing a ZIP. Choose a location outside the live archive, preferably approved separate storage. Restore to new folder verifies the ZIP and creates a separate runnable workspace. Existing data is not overwritten. Saved sign-ins are excluded and may need re-entry. Close the app before moving its complete folder; new archives use a relative Data path. Existing external archive destinations remain external until you restore or migrate them.

Confirm a pending saved report

In Reports & exports, search or filter the scanner and date. Choose Pending verification to limit the list. Select a file, open its PDF, then choose Review / confirm selected report. Record the correct report type and only the checklist items verified in the PDF. A pending label is not a failed QA test. Confirmation requires the authorized reviewer and evidence; the program does not accept a file from its filename alone.

Understand text reading

The PDF may be saved before its text is read. Automatic reading handles up to 20 unprocessed or changed PDFs per batch while open and reuses cached results. The dashboard shows cached, waiting and unreadable counts. Use Pause automatic PDF reading to stop future batches. A read error stays available for manual retry. Extracted printed results do not replace the approved QA procedure or reviewer.

Understand archive review

The Archive review tab groups connection/file issues, report labels, daily archive dates, monthly checklist evidence and informational duplicate/session notices. Counts refer to archive items, not confirmed clinical failures. Open a group for every original detail and the next step. For a missing date, update reports, review pending labels, and compare the actual scanner records with the department schedule, active-from date and approved exceptions. Do not change the schedule merely to remove a warning.

Save a support report

Export scrubbed logs creates a shareable ZIP with counts, QA archive date ranges, selected settings, reading status and Windows error numbers. It excludes PDFs, extracted evidence, filenames, source/archive paths, network addresses, usernames, passwords and raw logs. Scanner 1, Scanner 2 and so on follow your configured scanner order. The ZIP includes the summary plus all retained scrubbed activity: operation starts and outcomes, durations, per-scanner numbers, Windows codes and aggregate counts. Logs normally cover up to 90 days with a 50 MB storage limit; nothing is uploaded automatically. The standalone diagnostics tool can collect the same report while the application remains open. Raw activity logs are separate and may contain internal details.

Install an offline update

Open Updates, choose or drop one approved update ZIP, review the selected version, then choose Install checked update & restart. The app closes, the helper waits for the data lock to be released, installs the checked program files and opens the normal launcher. Reports, settings and saved sign-ins stay in place; previous program files are retained under Backups. A damaged package or still-open app stops installation. Use a trusted package: checksums establish file consistency, not authorship. No website connection, installer or administrator launch is needed. Older versions without an Updates tab require the one-time upgrade helper supplied separately.

Repair scanner connections

General packages use example network paths. Use Apply local connection profile in Advanced settings to select a private JSON profile with scanner paths and usernames. A bundled Config/NetworkProfile.local.json fills factory examples automatically; customized settings are preserved unless you explicitly apply a replacement. Profiles cannot contain passwords.

For an existing installation, close the app and run the private package's Apply CT QA Network Update.cmd, then select the existing program folder. The update preserves reports, review history, the archive location and unrelated Windows drive assignments. Enter passwords only in the secure sign-in prompt or password boxes in Advanced settings. Windows error numbers identify authentication, conflicting sessions, missing shares or denied folder access. If a share is accessible but a preferred drive letter is occupied, the program uses the UNC reports path directly.
