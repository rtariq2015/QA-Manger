Open the application

  1. Extract the entire ZIP into a folder on your Desktop. Do not run from inside the ZIP.
  2. Double-click Start CT QA Manager.cmd. Keep the App and Config folders beside it. No installation or administrator launch is needed.
  3. If Windows or hospital policy blocks it, leave the error window open and ask IT to approve or sign the application. The launcher does not change security settings.

Review a classification

In Report library, select the PDF and choose Review classification. Open the report, choose the correct category, enter your reviewer name and reason, then approve the reclassification preview. Confirm Monthly QA only after checking the department's requirements. A report containing one Monthly-related test may not be a complete Monthly set. Previous category copies are retained in private reclassification history, outside Reports; the master index points to the current reviewed classification.

Decisions are tied to the archived report's SHA-256 identity and recorded in the master index and retained review history. The application records reviewer attribution; Windows folder permissions and department procedures control who is authorized. It does not provide a separate user account or role system.

Advanced settings

Use this section for network paths, preferred drive letters, local archive location, candidate thresholds, expected schedules and active-from dates, coverage lookbacks, classification reviews, integrity audits, and activity history. Save settings before the next scan. The default archive location is the extracted application folder. Archive destinations must be direct local disk or USB folders; network destinations, mapped drives, junctions, and symbolic links are rejected to protect scanner sources.

Reconnect drives tries your existing Windows access first. Enter an authorized scanner account only in the secure credential prompt when requested. Passwords are not saved by the application. An occupied preferred drive or conflicting Windows session is left unchanged.

Where the files go

The chosen archive directory contains Reports, the searchable QA_Master_Index.csv, readable Activity.csv, and internal recovery state. Original filenames remain inside identity/session folders. Do not manually edit the internal state or move individual indexed files. Keep the archive and its metadata together when backing it up.

Daily updates compare source and destination metadata to avoid rereading unchanged PDFs. Changes that deliberately preserve size and timestamps are outside the fast cache's detection; use integrity audits for saved content checks. The full audit checks saved PDFs against indexed hashes; it does not reread unchanged scanner sources. PDF checks inspect the header, closing marker, and limited readable PDF hints; the app does not certify PDF safety or interpret every compressed test result.

If something goes wrong

  • One scanner is offline: available scanners can still update. Check the hospital network, saved path, and authorized access.
  • The destination is unavailable: select a writable local archive folder you are authorized to use. Do not choose a scanner source folder.
  • You cancel or the app closes unexpectedly: completed verified records are checkpointed. Incomplete transfers are never presented as completed reports. Run Update Reports again to resume safely.
  • The app cannot start: keep the launcher's error window open. Startup details are saved under %LOCALAPPDATA%\CTQAManagerPro\Startup.log (or your temporary folder if unavailable).
  • Corruption or conflicting archive state: keep the original files and metadata intact; consult IT and use the integrity audit before attempting repairs.
